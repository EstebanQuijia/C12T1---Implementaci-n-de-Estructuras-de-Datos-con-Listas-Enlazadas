# Tema 6: Listas Enlazadas, Pilas y Colas

Este repositorio contiene la implementación en Python de cuatro problemas prácticos resueltos utilizando **Listas Enlazadas Simples**, optimizando el almacenamiento y la manipulación dinámica de datos.

## Descripción de los Problemas

1. **Gestión de Procesos (SO):** Simula una tabla de procesos dinámicos mediante nodos enlazados, permitiendo agregar procesos, cambiar estados, eliminar terminados y priorizar elementos moviéndolos al inicio.
2. **Editor de Texto Básico:** Cada línea de un documento es representada como un nodo enlazado, permitiendo insertar, agregar y mostrar líneas de texto de forma secuencial.
3. **Gestión de Polinomios:** Almacena términos matemáticos ordenados por exponente mediante nodos, evitando guardar coeficientes con valor cero y permitiendo evaluar funciones polinómicas.
4. **Hoja de Cálculo Dispersa:** Utiliza una estructura enlazada para almacenar únicamente las celdas que contienen datos activos, ahorrando memoria frente a matrices bidimensionales tradicionales.
